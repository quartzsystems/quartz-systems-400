# The QGLDCLNT interface, one C prototype per line: the header letter
# (L LDAP, B LBER, S LDAPSSL), `-` when QS/400 refuses the function
# (it is exported and answers LDAP_NOT_SUPPORTED), then the prototype.
# runtime/ldapclnt generates QSYSINC/H(LDAP, LBER, LDAPSSL) and
# QSYSINC/QRPGLESRC(LDAP) from this file; its tests check each built
# function's entry against it.
