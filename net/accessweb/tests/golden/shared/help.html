Active jobs

Use this page to work with the jobs that are currently active on the system. The list shows every job in every active subsystem, including system jobs, unless a filter restricts it. This is the web equivalent of the WRKACTJOB command.

Filter

SubsystemShow only jobs running in the chosen subsystem. *ALL shows every subsystem.
UserShow only jobs whose current user matches the value. A generic name may end with *, for example QTMH*.
Job nameThe simple job name, up to 10 characters.
StatusOne of the active job statuses, for example RUN, DEQW, MSGW, LCKW, TIMW.

Columns

Job name / User / NumberThe three parts of the qualified job name number/user/name.
TypeBCH batch, INT interactive, ASJ autostart, PJ prestart, SBS subsystem monitor, SYS system.
StatusThe current job status. A job in MSGW status is waiting for a reply to a message and is shown in red.
CPU %Percentage of processing unit time used by the job during the elapsed interval.
FunctionThe current program, command or menu, prefixed with the function type (PGM-, CMD-, MNU-).

Actions

Hold holds the job (HLDJOB). Release releases a held job (RLSJOB). End opens the Confirm End Job page, where you choose a controlled or immediate end (ENDJOB). Job log shows the job's messages. Properties shows every attribute of the job. Spooled files lists the output the job has produced.
